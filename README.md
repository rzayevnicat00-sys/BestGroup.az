## 🚀 Quraşdırma Təlimatı

1. Yuxarıdakı **Releases** linkinə keçin və **`BestGroup.az.apk`** faylını yükləyin.
2. Telefonunuzda endirilmiş faylı açın.
3. Əgər sistem xəbərdarlıq edərsə, parametrlərdən *"Bu mənbədən quraşdırmaya icazə ver"* seçimini aktiv edin.
4. **Quraşdır (Install)** düyməsinə toxunub tətbiqi başladın.
5. Mövcud hesabınızla daxil olun və ya qeydiyyatdan keçin.
